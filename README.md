For this program:
1. Install and run blazegraph.
2. Create a config.py file with in the src root with a grp_endpoint string where the contents of the string is the localhost location of blazegraph (i.e: grp_endpoint = "http://127.0.0.1:9999/bigdata/namespace/kb/sparql").
